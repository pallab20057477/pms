BOOKINGHOTEL.CO.IN - API INTEGRATION SUMMARY
====================================================================

1. INVENTORY UPDATE API
--------------------------------------------------------------------
Purpose: Sent by the Hotel System to update inventory on the Channel Manager.
Endpoint: https://api.bookinghotel.co.in/api/Inventory/UpdateInventory

Payload Format:
{
  "Header": {
    "Username": "TestUser",
    "Password": "TestPassword"
  },
  "HotelId": "964",
  "RoomTypeId": "4841",
  "InfoDays": "12/08/2026|12/08/2026|0",
  "SoldOut": "0"
}

3. BOOKING CANCEL API
--------------------------------------------------------------------
- Endpoint: POST /api/public/channel-manager/bookinghotel/push
- The cancellation uses the exact same endpoint as booking creation.
- Payload Format: Identical to the booking creation payload, but with the following differences:
  1. `"BookingMode": "cancel"` (This triggers the cancellation logic in our system).
  2. `"ChannelBookingCancellationUniqID"` or `"ChannelBookingUniqId"` must contain the original booking reference so we can find and cancel it.

Expected Response:
{
  "Status": "Success",
  "ConfirmationNo": "<Booking Reference>"
}
